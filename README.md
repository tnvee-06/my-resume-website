# my-resume-website
Personal portfolio website for the IIM Bangalore DBE web development assignment.

- `index.html`: the content and structure (HTML only)
- `style.css`: the design (CSS only, no JavaScript, no frameworks)
- `media/`: the opening film, its poster image, the portrait and two editorial stills
- `robots.txt` + a `noindex` tag: ask search engines not to list the site (it is still public)
